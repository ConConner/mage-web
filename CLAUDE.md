# MAGE Web

Electron + React + TypeScript rewrite of MAGE Themes (Metroid Fusion / Zero Mission editor).

- Read `README.md` (architecture) and `docs/IMPLEMENTATION_NOTES.md` (ROM format findings, original-editor behaviors,
  gotchas, known gaps) before changing things.
- Layering: `src/core` (no DOM/Node) ← `src/platform` ← `src/main`/`src/preload` and `src/renderer`. Keep editor logic
  out of the Electron main process and DOM code out of `core`.
- Never write to the ROM while editing: everything editable is a project asset (`src/core/project`), and only the
  builder (`build.ts`) produces ROM bytes. New editable data = new asset kind (assets, codec, extract, build).
- Table locations, counts and names come from the ROM map (`src/core/game/map`, generated by
  `scripts/generate-rom-map.mjs` from mf-zm-info), not hardcoded offsets.
- New user actions are commands in `src/renderer/src/workbench/commands.ts`. Menu entries go in `src/shared/menus.ts`.
- Checks: `npm run typecheck`, `npm test` (add `MAGE_TEST_ROM=/path/to/rom.gba` for ROM integration tests, including
  "unchanged project builds byte-identical"), `npm run build`. Never commit ROM files.
- If Electron fails to start from an agent shell, run `env -u ELECTRON_RUN_AS_NODE npm run dev`.
